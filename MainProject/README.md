# 🏢 Urban Furniture Accounting System — Frontend & Main Application

For the full interactive documentation, architectural flowcharts, database ER diagrams, and system guide, please refer to the **[Main Root README.md](../README.md)**.

## Quick Run Instructions

```bash
# 1. Ensure PostgreSQL is running (from root directory)
docker-compose up -d

# 2. Push database schema (inside MainProject)
npm run db:push

# 3. Launch Development Server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to access the system.
